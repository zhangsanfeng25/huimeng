# 付款登录循环与底部导航局部修复

## 范围

- 在已有未提交改动上进行局部修复，未提交、推送或发布 GitHub Release。
- 关闭仅包裹图标的 Material 活动指示器，使用 checked 背景包裹图标和文字；调整上下内边距避免重叠。买家、商家共用。
- 付款页监听同步后的网络凭证变化，取消旧请求状态并重新读取结算单，立即刷新付款按钮。
