# 绘梦三端界面改版基线

源码基线为 `android-v1.2.0`（`164ce09`）。Android 在 API 34 模拟器运行独立 QA 包，管理员网页在 Chrome 连接本机演示库。Android 测试截图使用测试数据。工作台指标和例图数字均为演示内容。

## 页面清单

| 端 | 第一批代表页 | 后续覆盖 |
| --- | --- | --- |
| 买家 Android | 首页、底部导航、商品卡片、绘本详情 | 欢迎、登录、注册、找回密码、搜索和分类、评价、购物车、结算、演示支付及结果、订单与售后、社区和发帖、用户资料、会话与系统通知、个人中心、收藏等列表、地址、账户、外观、同步状态、入驻申请、AI 浮层 |
| 商家 Android | 工作台、商品与订单列表、商品表单 | 商品库存与审核状态、订单详情和售后、社区、消息、店铺及个人资料、图片裁剪、AI 浮层和共用设置 |
| 管理员 Web | 登录、工作台、侧栏、管理表格、审核详情 | 用户、商家、分类、商品审核、商品列表、订单、评价、通知、日志、社区、售后、反馈、系统设置、管理员账户、AI 管理及助手 |

基线源码包含 34 个 Android Activity、52 个布局 XML 和 17 条 Web 页面路由。布局数量包括列表项与底部弹层。

## 已观察的界面问题

| 优先级 | 证据 | 改版目标 |
| --- | --- | --- |
| 高 | 买家首页首屏的轮播、年龄和主题入口占据大部分高度，第一行绘本卡片的关键文字在首屏下方。AI 悬浮球遮住一个主题入口的图标。 | 保留年龄与主题入口，压缩首屏高度，给绘本标题、价格和浮层停靠预留空间。 |
| 高 | 管理员工作台首屏主要是指标和趋势图，待审核、待发货入口位于较下方的动态区。 | 让可处理事项在进入工作台后即可发现，同时保留指标与趋势。 |
| 中 | 买家详情缺少出版资料时出现连续占位行和只有标题的简介卡。 | 在缺失状态压缩占位区，维持购买动作、评价和联系入口的可达性。 |
| 中 | 商家工作台四种待办的视觉权重相近，商品列表空态依赖一行文字提示用户点击右上角。 | 优先显示当前需要行动的任务，并按无商品、无匹配和加载失败提供对应反馈。 |
| 中 | Web 审核详情首屏是长字段表，审核状态在字段表下方，提交时间在列表和弹窗使用不同格式。 | 让商品名称、审核状态和可用动作更容易确认，统一可读时间格式。 |

## 设计方向

- A 采用暖纸色、森林绿和柔和绘本插画，买家端强调绘本封面，商家和管理员端采用克制的同系强调色。
- B 采用云白、浅蓝紫和清晰的操作分组，买家端保留暖色封面，商家和管理员端强调任务列表。

两套例图用于确认配色、密度和层级。图中的示意按钮、指标、导航数量及数据以真实功能核对结果为准。正式改造前确认一套方向，随后同时检查深浅色、键盘或系统返回、窄屏与大字体。

## 验证边界

已观察 Android 登录、买家首页与绘本详情、商家工作台与商品空列表，以及 Chrome 管理员登录、工作台、商品审核列表和审核详情。审计阶段仍需逐页覆盖关键状态，审核详情本次观察的是已通过样例。

API 34 隔离包设备回归运行 71 项，67 项通过、4 项断言失败。其中两项为同一条「忘记密码」文案断言被继承后重复执行，另有 AI 聊天输入测试写死正式包名，以及首页轮播横滑断言失败。轮播失败原因仍待复核，列入买家端改版回归。
