## 实现与核对

- 私有 SQLite 保存空间、业务投影、确认快照、操作队列、回执、分页和元数据，启用 WAL 与外键；本地改动与入队同事务。已有购物车只迁移一次；不支持的数据升级明确失败而不删库。图片写入应用私有目录，原子改名并校验 SHA-256。
- 支持本地目录、搜索、筛选、详情和评价缓存；资料/头像、地址、默认地址、购物车、收藏、消息，社区帖子/评论/点赞，商家申请/商品草稿/送审意向，以及订单创建、付款、取消、收货、发货和物流意向。
- 网络登录只用于账号验证与关联；无服务、令牌失效或退出网络登录不会强制退出本地空间。不同账号和服务地址隔离；既有账号空间合并保留原内容。注册与修改密码仍需在线，不把密码写入操作队列。
- 前台单协调器依次上传图片、上传操作、拉取完整快照；每次回调检查当前空间和代次，后台暂停。操作 UUID、首次发送载荷和 hash 冻结；响应丢失重试核对原回执。退避上限五分钟，尊重 Retry-After。同一记录的延迟重试不允许被更新的操作抢先发送。
- 网站 HTTP 路由与同步复用业务服务与校验，服务器事务内提交业务和回执，提交后再发事件。每次重新核对当前权限；同步认证中间件只作用于 /sync，避免阻断管理员页面。
- 价格、库存、金额、订单版本、状态和图片归属仍由服务器判定；离线付款/收货/发货/送审显示待确认，绝不显示网络成功。示例订单不上传、不扣真实库存。
- 冲突页显示本地与最后网络内容；安全的资料修改可生成新操作重新确认，采用最新同类编辑，其他类型修改继续保留。保留网络版本会归档本地编辑，不删除图片，不撤销服务器可能已完成的操作。订单等需返回业务页重新核对。
