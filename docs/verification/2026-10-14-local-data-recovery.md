## 原因与修复

1. 上版初始空间只放入 SampleCatalog 的一本书，且未登录时协调器在探测服务之前就返回，造成旧内容缺失和连接状态误导。当前公开初始内容导入 SQLite，示例种子只留在测试源码；无登录令牌也能探测服务。
2. 按用户选择迁移当前原账号完整数据，其他账号私人内容不导入。LocalDataImporter 复用确认快照导入机制，在同一事务中保留未上传的本地投影与队列；账号不符拒绝导入。个人数据只写入当前设备的私有 SQLite，不进入 APK。
3. APK 仅携带公开商品、公开帖子/评论/评价、广播通知与现存公开图片；图片映射保留原服务器 URL，显示时可读 APK 资产，后续编辑不会把资产 URI 当作网络上传路径。已同步或已导入的账号不会被初始公开快照覆盖。
4. 启动日志显示 18:30 的第一次启动进行了 API 8.8 秒、网页 19.0 秒的编译，约 33 秒才可用。交付前预构建并校验缓存；指纹扫描复用目录项，去掉对每个文件重复的 exists/readdir 异常探测，仍完整读取内容并验证 SHA-256。源码/产物损坏但 mtime 不变的回归保持通过。
