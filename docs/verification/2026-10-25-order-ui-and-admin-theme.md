# 订单详情、分类筛选与后台主题本地验收

日期：2026-10-25。范围为已确认的五项局部调整，保留工作区既有数据库规范化与退款状态改动。

## 本次行为

- 买家订单详情优先显示 `remoteId` 平台订单号；未同步订单标注本地待同步。长按可复制平台号及本地编号，不修改订单主键或同步映射。
- 订单进度默认显示当前状态和最新一条实际事件；多条记录时可展开、收起。自动刷新及页面重建保留展开状态。
- 派送中订单金额下显示自发货起30天的剩余天数；进行中售后显示暂停提示，全额退款或已完成订单不显示待收货提示。相同订单数据也重新计算倒计时。
- 服务端启动、每分钟及订单相关请求时检查自动收货。仅处理派送中、发货已满30天、没有进行中售后且没有全额退款的订单。更新状态、版本、完成时间、实际事件及双方通知在同一事务中提交；重复执行不重复生成。
- 售后结束且没有全额退款后，以原发货时间继续判断。系统离线停机期间不执行；重启后补查。缺少或无效发货时间的历史订单保留原状态，不猜测发货日期。
- 分类管理的“全部状态”替换为按上级分类筛选的“全部分类”。选项包含接口预设与最新记录的上级分类，新增后随数据刷新显示。其他管理页面保留状态筛选。
- 修复分类新增表单的默认下拉值校验，显示默认“已启用”时无需重复选择。
- 后台详情文字、搜索框、下拉选项、操作链接、错误提示及部分表单统一遵循当前主题颜色。
