# 商家端第一轮精简与操作优化

范围：用户批准的第一轮 Android 商家端调整；保留已有紫色、圆角卡片设计。本次未上传 GitHub、未创建正式发行版、未操作业务数据库。

## 已实现

- 工作台：四项可点击待办（待发货、待处理售后、商品待修改/提交、未读消息），压缩经营概况，保留新增商品与全部商品/订单入口。
- 商品：名称/编号搜索、状态筛选、动态分类筛选、重置与结果数量；切换页面保留筛选条件；卡片和操作按钮均可进入管理。
- 订单：订单号/买家/商品搜索、状态筛选；工作台待发货数字与列表共用条件；退款和进行中的售后会影响可执行物流操作。
- 导航：工作台、商品、订单、消息、我的；社区与阅读笔记移至“我的 → 内容运营”，保留原有社区功能。
- 消息：底部角标合计买家会话与系统通知，两类页面的前台轮询、下拉及本地数据刷新都会更新两路计数。
- 商品表单：新增与编辑均支持“保存并送审”，先保存当前输入再提交审核；保存失败不送审，送审失败保留已保存草稿并允许重试；审核中或送审待同步时只读；下架增加确认。
- 售后：按“待我处理 / 等待他人 / 已结束”筛选；工作台不把等待平台审核计入商家待办。
