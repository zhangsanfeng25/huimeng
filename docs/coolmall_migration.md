# 青商城迁移说明

“青商城（CoolMallKotlin）”用于绘梦书城 Android App 的视觉和业务流程参考，不直接复制其 Kotlin + Jetpack Compose 技术实现。本项目继续采用实施文档确定的 Java + XML，并与现有 Node.js + Express + SQLite 服务共用 `/api/v1` 接口。

## 页面与模块映射

| 青商城参考模块 | 绘梦书城实现 | 当前接口 |
| --- | --- | --- |
| 首页、搜索、分类、商品瀑布流 | 买家首页、绘本检索、适龄/主题分类、双列绘本卡片 | `GET /catalog/categories`、`GET /catalog/products` |
| 商品详情 | 绘本封面、名称、价格、适龄、简介、库存、试听和 3D/AR 占位 | `GET /catalog/products/:id` |
| 购物车 | 商品数量调整、删除、金额合计 | `GET/PUT/DELETE /me/cart` |
| 确认订单与支付 | 地址、订单确认、模拟支付 | `POST /checkout`、`POST /checkout/:groupId/pay` |
| 订单与物流 | 待付款、准备出库、待发货、已发货、运输中、派送中、完成 | `GET /me/orders`、物流推进与确认收货接口 |
| 评价 | 绘本评分与评价列表 | 商品详情评分数据、评价管理接口 |
| 我的 | 订单、收藏、地址、购物车、设置、切换商家端 | `/me/*` |
| 商家中心 | 商品、订单、社区和店铺资料 | `/merchant/*` |

## 已迁移的设计语言

- 绿色品牌主色、浅色卡片背景、圆角卡片与低阴影。
- 首页搜索优先、横向分类、活动 Banner、双列商品流。
- 统一的现代线性底部导航图标。
- 商品详情底部固定双操作按钮。
- 购物车卡片、步进数量控制与固定结算栏。

## 当前 Android 实现进度

- 买家：注册、登录、忘记密码、首页、搜索、分类、详情、收藏、购物车、地址、结算、模拟支付、订单、确认收货、评价、社区、评论、消息和个人中心。
- 商家：商品列表、新增与编辑草稿、商品预览、提交审核、已上架商品下架、多阶段订单处理、社区发布、通知和店铺资料；底部导航固定为“商品、订单、社区、我的”。
- 跨端：商品审核状态、订单状态、社区内容和通知均使用现有 SQLite 数据，经 `/api/v1` 在 Android 与网页后台之间同步；买家订单、商家订单和订单详情每 5 秒自动刷新，后台继续通过事件流刷新。

## 本轮新增

- 启动欢迎页使用已确认的第二张“薄荷森林立体小熊”壁纸，提供右下角立体跳过按钮、中央进入按钮和自动进入。
- 买家“我的”提供身份切换；具备商家权限的账号可进入商家端，商家“我的”可返回买家端，不需要退出登录。
- 设置页提供浅色、深色、跟随系统三种模式，文字、卡片、图标背景与系统夜间模式同步适配。
- 订单物流使用独立 `logistics_status` 保存细分状态，并记录 `order_events` 时间线；商家推进状态后买家列表与详情会同步显示。
- 应用内壁纸已经按用户确认同时加入“薄荷晴空”和“紫蓝梦境”，设置页可在默认纯色与两张壁纸之间切换；选择保存在本地外观配置中，并对买家端和商家端共同生效。

## 保留的绘梦书城要求

- 买家底部导航固定为：首页、社区、消息、我的。
- 购物车入口位于首页右上角，并将在“我的”中保留快捷入口。
- 商品详情保留试听按钮以及 3D/AR 占位入口。
- 支付、发货均为本地模拟操作，不接入真实资金与物流平台。
- 登录、注册、找回密码、修改密码均调用数据库接口；密码采用带随机盐的散列保存，会话只保存令牌摘要。
- 管理后台 `huimeng/html` 保持现状，不因 Android 视觉迁移而覆盖。
