# 绘梦 AI 本地联调

Android Debug 默认连接 `http://10.0.2.2:3000/api/v1/`。后台在「系统管理」下提供「AI 管理」。同一个服务端为后台和 Android 提供接口。

## 使用临时数据库演练

确认 3000 端口可用后，在项目根目录构建网页和服务端。

```powershell
npm run build
Set-Location server
$env:DATABASE_PATH = [IO.Path]::GetFullPath('../output/ai-qa/demo.db')
$env:UPLOAD_DIR = [IO.Path]::GetFullPath('../output/ai-qa/demo-uploads')
$env:HOST = '127.0.0.1'
$env:PORT = '3000'
$env:DEMO_MODE = 'true'
$env:HUIMENG_AI_DEMO = '1'
npm run db:migrate
npm run db:seed
npm run start
```

1. 打开 [本地管理后台](http://127.0.0.1:3000)，使用项目的演示管理员账号登录。
2. 在「AI 管理」勾选「启用 AI 助手」并保存。模拟对话可以留空接口地址、模型和 Key。点击后台右下角的悬浮球，试问「近 30 天有多少笔订单」或「最近有哪些热门绘本」。
3. 在 Android 模拟器用项目的演示用户或演示商家账号登录。点悬浮球后直接提问，如「推荐一本适合 5 岁孩子的绘本」或「我店里有哪些绘本缺货？」换身份时先退出，再在登录页选择另一身份。
4. 测试退出与恢复同步时，在「同步状态」核对待处理记录。升级前身份可确定的操作随原身份继续同步，需确认身份的旧记录可以在该页逐条处理。

## 接入真实服务商

可在「AI 管理」填写任意提供 OpenAI 兼容 Chat Completions 的公开 HTTPS 服务。地址使用服务商文档中的基础地址（通常以 `/v1` 结尾）或完整的 `/chat/completions` 地址，模型填写该服务商的模型 ID。更换接口地址时请同时填写新接口对应的 API Key。勾选「启用 AI 助手」并保存时，系统先请求模型生成简短答复；成功后配置对三端立即生效。验证失败会保留上一份已保存配置。商品卡片始终由服务端目录生成。

服务端根据当前角色、问题和最近对话识别常见业务意图，将问题、近期对话及对应角色能访问的只读数据发给模型。旧客户端发送的 `feature` 仍按身份校验。商品资料中的文字按数据处理。

- 用户的绘本推荐和社区热门入口可获得已筛选的在售商品。阅读咨询与自由对话使用用户输入和当前对话历史。
- 商家的文案入口最多获得六件本店商品资料，优先提供问题中明确提到的商品。社区需求分析使用公开帖子和公开评论的主题计数，不发送发帖人资料或帖子原文。店铺经营建议使用本店订单与库存汇总。
- 管理员的平台趋势和数据分析入口可获得近 30 个 UTC 日期的逐日订单笔数及平台汇总。运营建议使用平台汇总，商品热度使用在售商品与公开社区热度。

真实使用时将服务端的 `HUIMENG_AI_DEMO` 设为 `0` 并重启。服务端本地的 `HUIMENG_AI_MASTER_KEY` 使用随机的 32 字节 Base64 值；配置已有主密钥时需要保留原值。Key 以 AES-256-GCM 加密存入本地 SQLite，网页和 App 均不会收到已保存的 Key。
