# 绘梦界面补充与商家申请（1.0.33）

沿用现有 Java/XML、奶白背景、紫色按钮、圆角卡片和网页管理组件，未更换技术栈。

## 页面与入口

- 首页搜索按钮打开独立搜索页：账号隔离的最近八条搜索历史、清空历史、综合/最新/价格双向排序、分页、空态和失败重试。
- 首页全部分类、搜索页分类按钮打开独立分类页；选择分类后进入该分类的商品结果。
- 商品详情「查看全部评价」打开独立评价页，只显示公开且未删除的评价，支持分页与重试。
- 商家商品新增/管理页可从图库选择最多九张图片，逐张裁剪上传，点击预览、移除、设为封面。第一张作为封面，图片保存在共用服务。审核中的商品不能编辑。
- 我的 → 切换身份 → 申请成为商家：填写店铺名称、联系人、联系电话、经营地址、店铺介绍，并确认资料真实。提交后可查看进度；驳回时显示原因，可修改后重新提交。
- 网页管理端 → 商家管理 → 查看：展示申请资料，提供「同意申请并开通商家」「驳回申请」，驳回原因必填。
- 审核结果通过实时事件同步至当前 App；通过且营业的用户无需重新登录，即可切换商家身份。店铺停用后旧会话也会失去商品管理权限。

## 更新与使用

1. 在现有控制中心关闭并重新打开服务，加载更新后的后端和网页。启动流程执行增量迁移 `007_merchant_application`，保留现有业务数据和素材。
2. 安装 `output/interface-completion-20261004/huimeng-1.0.33.apk`（versionCode 23）。交付包使用默认模拟器地址 `http://10.0.2.2:3000/api/v1/`。
3. 真机需要将服务绑定到局域网，并使用 `-PapiBaseUrl=http://电脑局域网IP:3000/api/v1/` 重新构建。
