# 绘梦书城后续优化与内容增加方案

## 一、优先级 P0：完成可安装与真机闭环

1. 在安装 Android Studio、Android SDK 35 的电脑上完成 `assembleDebug`，生成 APK。
2. 使用 Android 模拟器和至少一台真机验证欢迎页、注册登录、角色切换、购物、订单物流、壁纸与深色模式。
3. 修复不同尺寸屏幕上的文字截断、键盘遮挡、状态栏和底部导航适配问题。
4. 配置正式签名、HTTPS API 地址和 Release 网络安全策略，生成可提交的正式安装包。

## 二、优先级 P1：业务完整度提升

### 买家端

- 增加优惠券、满减、搜索历史、浏览历史和猜你喜欢。
- 增加订单取消、超时关闭、退款申请及售后进度。
- 完善物流详情：承运商、运单号、物流节点、预计送达时间。
- 增加社区帖子多图、点赞、收藏、举报和作者主页。
- 将试听功能接入真实音频播放器，记录播放进度。

### 商家端

- 增加订单筛选、批量发货、运单号录入与库存预警。
- 增加商品多图上传、规格管理、草稿自动保存和审核记录。
- 增加经营数据：销售趋势、热销商品、订单转化、退款比例。
- 增加社区内容编辑、删除、评论管理和违规提醒。

### 管理后台

- 增加轮播图与首页推荐位的可视化排序。
- 增加退款审核、举报处理、敏感词、操作日志筛选与导出。
- 增加角色权限配置，使管理员、运营和客服看到不同菜单。
- 增加数据图表日期筛选及 Excel 导出。

## 三、优先级 P2：稳定性与安全

- 为登录、下单、支付、发货、退款等接口补充集成测试。
- 增加图片类型、大小、尺寸校验及自动压缩。
- 增加密码重置验证码流程，替换当前本地演示式直接重置。
- 增加访问令牌续期、异常登录提醒、接口权限审计和数据库备份。
- 将高频订单同步从 5 秒轮询升级为 WebSocket 或 Server-Sent Events。
- 增加崩溃日志、接口耗时监控和错误追踪。

## 四、优先级 P3：儿童绘本特色内容

- 建立按年龄、主题、能力培养、阅读时长划分的绘本标签体系。
- 增加亲子共读计划、每日阅读打卡和成长勋章。
- 增加绘本内页试读、语音伴读、阅读时长记录。
- 将现有 3D/AR 占位扩展为资源下载、模型预览和扫码触发。
- 增加编辑精选书单、节日专题、作者与出版社专题页。

## 五、建议实施顺序

| 阶段 | 建议内容 | 验收成果 |
| --- | --- | --- |
| 第一阶段 | Android 真机适配与 APK 签名 | 可安装 APK、真机测试记录 |
| 第二阶段 | 退款售后、物流、商品图片上传 | 完整交易闭环 |
| 第三阶段 | 后台权限、运营位、数据导出 | 可实际管理和运营 |
| 第四阶段 | 阅读打卡、语音、3D/AR | 形成绘本商城特色 |
| 第五阶段 | WebSocket、监控、备份与安全加固 | 达到稳定部署标准 |
