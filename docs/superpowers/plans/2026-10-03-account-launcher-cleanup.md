# 账户页、服务控制中心与项目清理实施计划

**目标：** 简化账户页；修复控制中心按钮响应、启动和闪屏；清除确定不用的历史产物，保留所有数据库和实际素材。

**实现：** Java/XML 账户页沿用当前设计，密码可选并与资料事务提交。PowerShell WinForms 通过后台 runspace 查询/关闭服务，界面计时器只收取结果。现有构建缓存继续复用；依据实际引用清理。

**约束：** 不删除数据库、备份数据库或当前业务素材；不安装依赖；不更换技术栈；不使用子代理。

## 任务

- [x] 账户页：去掉头像名字及常驻说明，保留无障碍名称、错误/进度反馈；一个保存修改按钮。密码留空仅更新资料；错误旧密码/用户名冲突不能部分保存；成功改密码清理会话。
- [x] 回归：隔离数据库测试资料和密码同时保存/失败回滚；Android 验证一个按钮、无头像名字、默认头像选择及暗色/窄屏。
- [x] 控制中心：后台查询及关闭；缓存进程身份；忙碌状态明确；验证延迟系统查询期间按钮与重绘继续响应，实测停止/启动服务。
- [x] 闪屏与启动：显示前完成字体/布局，双缓冲；消除不必要子进程和同步日志清理；测量首次启动和缓存启动。
- [x] 网站：按路由延迟加载，静态版本资源缓存；测量登录页面加载及主要页面交互。
- [x] 清理（用户已确认，749 个文件及 56 个空目录已移除，全部数据库和在用素材保留）：生成引用与大小清单，移除旧压缩包、旧 APK、截图和确认不用的素材/脚本；所有数据库及其配套备份素材保留，清理后检查图片路径。
- [x] 验收：构建、相关测试、UI 实际渲染；保存新版 APK、测量结果与删除清单；更新运行说明。

**验证重点：** 密码留空、错误密码、重复点击、迟到请求；运行/停止/端口冲突；UI 查询延迟；数据库中图片路径及备份恢复；窄屏暗色；当前用户资料不可被测试修改。
