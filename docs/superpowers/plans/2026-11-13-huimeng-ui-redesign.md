# 绘梦三端界面改版实施计划

**范围**　以 1.2.0 为基线。买家端采用绘本导览，商家和管理员端采用目录优先。Android 使用现有 Java/XML，网页使用现有 React/TypeScript/Vite。

**依据**　[三端界面审计](../../verification/2026-11-13-ui-redesign-baseline.md)及确认的组件预览。

**设计规范**　买家以暖纸色、森林绿和封面构成阅读层级。经营端使用浅蓝紫和中性色，优先展示可处理任务和列表。状态同时以文字与颜色表达。复用现有图标和系统字体。Android 交互目标至少 48dp，网页提供可见焦点和减少动态效果支持。各端沿用已有主题设置。

- [x] 买家首页与详情。首屏依次展示搜索、短轮播、年龄及主题和双列书架。详情按内容显示出版资料与简介，保留目录、作者和读者评价入口。
- [x] 买家主要流程。购物车为空时提供找书入口，加载失败可重试。购物车、结算和订单详情的底部操作区独立占位。社区发布入口移到标题旁，消息操作栏和个人资料支持文字换行。
- [x] 商家主要流程。工作台首屏集中待办及经营摘要。商品与订单列表提供新增、清除筛选或重试入口。商品编辑区按基本信息、图书资料和素材组织，保存与送审始终可见。
- [x] 管理员主要流程。登录、导航、工作台、列表与审核详情采用同一视觉层级。审核首屏显示封面、版本及状态，待审核版本可直接聚焦审核说明。社区、售后和反馈复用列表与筛选布局。

## 主题与交互

Android 买家使用现有 `auth_cream`、`auth_accent` 和 DayNight 资源。商家用 `surface_soft` 和 `cool_green` 组织筛选与待办。导航胶囊沿用半透明资源，主要操作支持触控及大字体。Web 表格和弹窗使用 `surface`、`surface-2`、`border` 及可配置强调色。窄屏在表格区域内横向滚动。键盘可跳到主内容，关闭弹窗后焦点返回原入口。现有主题、壁纸及减少动态效果设置继续生效。

## 验收

- Android Debug 和测试 APK 构建通过，Lint 为 0 个错误、539 条警告。API 34 隔离包 16 项浅色定向用例通过，覆盖首页横滑、找回密码、长地址结算、购物车、社区、商家筛选及编辑、AI、详情目录和窄屏布局。深色模式下另有 3 项定向用例通过，覆盖买家与商家导航、首页、结算和绘本详情。
- Chrome 在 1440px 和 390px 验证登录、工作台、审核焦点、驳回原因及状态更新、订单队列和深色表格。另逐个打开 13 条管理路由检查渲染与页面溢出。测试使用隔离演示库。
- `npm run lint`、`npm run build` 和完整 `npm test` 通过，后者包括 142 项服务端用例。涉及 Windows 目录联接的用例在宿主权限下运行。
- 真机、真实账号、跨浏览器以及全部页面的状态组合仍需验收。改版保存在本地工作区，GitHub 上的 1.2.0 是改版前的发行基线。

## 布局复查

- 五张首页轮播使用 1850×850 原图，容器按当前宽度计算高度。底栏始终显示标签，选中状态通过图标颜色表达。内容区和底栏各自占位。
- 窄屏或大字体首页把主题图标放在文字上方，绘本列表改为单列。绘本名称和分类可以换行，详情购买区、评价、付款结果、社区操作、店铺资料和外观设置按内容调整高度。
- 买卖双方可在订单详情展开历史进度。售后初审和物流弹窗支持滚动，键盘弹出时仍可访问表单。
- Chrome 在 320px 宽度下检查了 16 条管理路由的浅色和深色显示，另验证两种主题下的审核弹窗可以滚动且没有页面横向溢出。Android 的 52 个布局 XML 均通过解析。各页面的实际业务状态覆盖以运行用例为准。
- API 34 通过 10 项常规和 4 项 320dp、1.5 倍字体深色用例。复看大字体截图后调整首页标题栏，再次验证问候语、主题标签和导航的可见区域。Android Lint 为 0 个错误、542 条警告。后台类型检查和构建通过。
- 搜索和收藏复用首页的绘本列数规则，作者主页在窄屏和大字体时改为单列。搜索排序支持换行，收藏空态可进入找书，收藏与地址的加载错误可在原页重试。九个输入页面显式在键盘出现时调整布局，裁剪预览按可用区域保持 1:1 或 4:3。
- 后续 API 34 隔离包通过 14 项定向用例，覆盖搜索、分类、评价、商家申请、裁剪尺寸、地址、账户和编辑返回。收藏空态跳转与作者主页另通过 2 项用例。最终 Android Lint 为 0 个错误、543 条警告。裁剪用例覆盖短视口测量，尚未覆盖真机相册和软键盘组合。

## 模拟器与控制台联调

- 在 API 34 模拟器的商家页面新建绘本、改书名和价格、提交审核。联调发现商品的本地编号与远端编号会导致连续保存和送审误报版本冲突。修复后，操作队列复用已有记录编号，并优先匹配精确的本地记录。真实联调用例和本地同步回归共 6 项通过。
- 买家从模拟器结算付款、发送咨询、提交反馈和申请售后，商家回复咨询。管理员网页保持打开时收到新增反馈。
- 通过控制台的启动按钮处理器启动共用服务，Chrome 从控制台端口读到同一测试库的订单、反馈、售后申请，以及修改后的绘本名称、31.25 元价格和待审核状态。控制台按钮通过测试脚本触发。所有写入使用隔离库。
