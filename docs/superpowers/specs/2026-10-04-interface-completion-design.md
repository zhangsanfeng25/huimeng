# 界面补充与商家申请设计

用户已要求直接完成三个界面模块与商家申请审核闭环，沿用现有格式、配色、圆角与 Java/XML、React 技术栈。此文件记录执行依据，不新增风格选择。

1. 商品评价：商品详情保留评价摘要，全部评价进入独立页面；分页读取公开、未删除的评价，支持加载、空内容、失败重试。
2. 商家商品图文：新增与编辑商品支持图库选择、已有裁剪、最多九张图片、首图封面、移除、设为封面与点击预览。商品修订保存已有封面、详情图和音频，审核期间不允许编辑；图片必须是本人上传或属于当前商品的已有图片。
3. 搜索与分类：新增独立搜索页与分类页，保留首页原有筛选；支持账户隔离的搜索历史、清空历史、价格/最新排序、分类筛选、分页与详情跳转。
4. 商家申请：我的→切换身份页面下方增加申请按钮。表单包含店铺名、联系人、联系电话、经营地址、店铺介绍及真实性确认；待审只能查看，通过可切换，驳回显示原因并允许重新提交。
5. 网页审核：原商家管理实时展示申请，详情展示申请资料；明确通过/驳回操作，驳回必填理由。通过时原子更新商家状态与角色；停用/撤销审核权限立即失效，服务端决定权限。
6. 同步：网页沿用 SSE；App 申请和切换身份页面前台连接鉴权 SSE，更新时读取自己的申请和权限，断线时每五秒重试读取，恢复前台重新核对。通过后无需重新登录，点击商家卡片由服务端验证并切换会话身份。
7. 兼容性：保留业务数据库与上传素材，增量迁移；没有 Git 元数据，保留本次修改原文件备份，不创建仓库或提交。验证使用临时数据库。
