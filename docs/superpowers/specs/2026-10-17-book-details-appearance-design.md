# 商品详情与外观设置补充：页面规划

日期：2026-10-17。阶段：页面与数据方案待用户确认，尚未修改产品代码或业务数据。

## 1. 目标与已确认范围

沿用绘梦书城现有 Java/XML Android 界面、紫色操作按钮、深蓝文字、现有壁纸及浅深色主题。参考用户图 3—5 的信息层级与卡片，参考图 6—7 的顶部圆角底部弹层；不是照搬参考软件的黑白配色。

用户已经确认：现有商品为虚构内容，作者、出版社、日期、目录、简介可以自行编写，作者简介应朴实合理。此规划覆盖当前数据库 P0001—P0020 共 20 本演示商品；不会将现实同名书籍的出版信息套入这些虚构商品。

## 2. 当前情况

- 外观页已有默认纯色及五张壁纸的控件。更换头像按钮被放在第一行壁纸容器内，且占满整行，挤出了默认纯色、薄荷晴空和紫蓝梦境，造成入口缺失及空白。
- 商品详情已有封面图集、收藏、名称、价格、适龄、库存、简介、店铺、用户评价及购买栏，音频按钮按音频地址显示。
- product_revisions 当前没有作者、出版社、出版日期、目录或作者简介字段；这不是只增加前端静态文字就能完成的改动。
- 当前版本支持本地离线使用。Android 本地 SQLite 以 JSON 保存商品，已有 bootstrap/public.json 初始化和联网快照同步；新增资料必须覆盖首次安装、旧版升级及联网同步。
- 工作区已有尚未提交的 1.1.2 分类浏览改动。本次实施需保留这些修改。

## 3. 方案 A：沿用现有风格的圆角资料卡

依据 mobile-android-design 的 Material 卡片、底部弹层、主题语义色及 48dp 可点击区域原则，保留当前项目已有视觉规范。它是依据设计原则整理的适配方案，不是新的内置模板。

| 界面 | 规划 |
| --- | --- |
| 外观与壁纸 | 更换头像独立一行；六个背景选项按三列两行显示；恢复纯色入口，补充选中与再次点击取消的反馈。 |
| 商品详情 | 保留封面、收藏和底部购买栏，增加紧凑的出版资料、分段简介、目录/作者卡片、编辑推荐、读者书评与相似推荐。 |
| 目录弹层 | 从底部打开，顶部约 28dp 圆角、拖动提示、标题与关闭按钮；正文滚动、章节分行，余白处使用浅色点线。 |
| 作者弹层 | 同一套顶部圆角容器；按文字作者、绘图作者分段显示；正文自然排版，支持滚动，不强行拉大行距。 |

普通资料卡约 20dp 圆角、16dp 内边距、12—16dp 区块间距；沿用当前文字和主题颜色。壁纸上卡片采用足够实的表面色，正文和弹层不使用透明文字底板。暗色模式同步适配。320dp 宽度及放大字体时允许卡片内容换行，必要时目录与作者卡片纵向排列，不固定正文高度。

## 4. 背景选择规则

选项为：纯色背景、薄荷晴空、紫蓝梦境、暖霞书页、深海微光、绿野花园。纯色背景使用当前主题的默认底色：浅色米白、深色深蓝灰。

- 点击未选项：立即应用；紫色边框、勾选及“当前”说明同步更新。
- 点击其他项：切换背景，保持单选。
- 再次点击同一项：取消显式选择，恢复跟随当前主题的默认底色，不改变浅色/深色/系统主题选择。
- “未选背景”与“明确选择纯色”保存为不同状态；取消后无卡片保持选中，避免纯色选项无法取消。
- 买家和商家业务页面共用设置，重启保持；登录、注册和欢迎页继续保留各自既有主题。

## 5. 商品详情顺序与交互

1. **封面与交易信息**：采用预览中的紧凑封面与右侧资料布局，减少首屏大图占高；保留封面左右滑动及点击查看大图、名称、收藏、价格、适龄、分类、库存及店铺。窄屏或放大字体时顺序排布，交易操作保持。
2. **出版资料**：文字作者、绘图作者（如有）、发行出版社、发售日期。日期以年月日显示；与数据库创建时间分开存储。
3. **图书简介**：每本约 150—260 字，按故事梗概、阅读特点、适合共读场景分为两到三段；默认显示四行，点击“展开全文”可查看全部并收起。
4. **目录 / 作者**：两张并列预览卡，目录显示前 3—4 项，作者显示简短摘要；整卡可点击，分别打开完整弹层。
5. **编辑推荐**：约 60—100 字，说明阅读亮点或亲子共读方式；明确区分于读者真实评分。
6. **读者书评**：使用现有公开评价、实际评分和数量，显示少量预览与“查看全部评价”；没有评价显示空态，不编造评价、用户、评分或数量。写评价继续沿用已购订单的既有入口。
7. **相似推荐**：优先同分类、适龄相近的当前可见在售商品，最多 4 本，排除本书、重复项及不可见商品；点击进入对应详情。数据不足则按实际数量显示，不复制卡片充数。
8. **固定底栏**：加入购物车、立即购买，保留现有库存和数量校验；滚动内容预留底部安全间距。

从商品详情移除试听按钮和对应点击入口；兼容保留历史音频数据，不因隐藏入口删除用户资料。

## 6. 两种底部弹层

目录和作者简介使用相同组件规则：最大高度约为可用屏幕的 85%，适度内容可自然收缩；顶部圆角约 28dp，底部贴合系统安全区。标题、关闭按钮固定，正文单独滚动。支持关闭按钮、系统返回、点击遮罩及下滑关闭。

长目录标题换行，点线只占当前行剩余空间，避免穿过文字。没有章页数据时不编造页码；图片书可使用“故事段落 / 共读导读”结构，避免将短篇绘本硬编成学术章节。

旋转屏幕或重建时恢复打开的弹层及内容位置；空资料显示“暂未填写”，不显示无法使用的箭头。目录不是全文阅读入口，作者卡也不增加关注或社交功能。

## 7. 内容示例：晚安，小熊

以下均是本项目的虚构图书设定，实际填充时为 20 本书分别编写，不使用一套模板反复替换书名。

- 文字作者：林禾；绘图作者：陈悠。
- 发行出版社：绘梦童书出版社（虚构）。
- 发售日期：2025-09-01（虚构出版设定）。
- 简介方向：小熊在傍晚与森林里的朋友一一道晚安；通过温和的重复对话和熟悉的睡前约定，表达从兴奋到安心的情绪变化，并给亲子共读留下观察画面和交流的空间。
- 目录：森林的傍晚、还不想睡的小熊、向朋友们说晚安、妈妈的睡前约定、月光下的梦、亲子共读小提示。
- 林禾简介：关注儿童的日常情绪与家庭陪伴，常从散步、观察自然和睡前聊天中寻找故事。创作注重简短语言、重复节奏和便于亲子共读的对话。不编写奖项、名校、销量及真实出版经历。
- 陈悠简介：以柔和色彩描绘森林、动物和家庭场景，注重画面中能让孩子主动观察的小细节；不杜撰现实机构背景。
- 编辑推荐方向：将“说晚安”变成可以共同参与的小游戏，提供两到三个简单的共读提问，不宣称治疗或保证学习效果。

## 8. 数据字段与维护链路

将“数据库中的子名字段”先按商品资料字段及显示名称理解，保留现有商品名称和 ID，不随意重命名既有列。

在商品版本 product_revisions 中增量添加：

| 数据库字段 | API / 本地 JSON | 用途 |
| --- | --- | --- |
| author_name | authorName | 文字作者 |
| illustrator_name | illustratorName | 绘图作者，可空 |
| publisher | publisher | 发行出版社 |
| publication_date | publicationDate | 发售日期，YYYY-MM-DD |
| author_bio | authorBio | 作者简介 |
| illustrator_bio | illustratorBio | 绘图作者简介，可空 |
| contents_json | tableOfContents | 有序目录数组 |
| editorial_review | editorialReview | 编辑推荐 |
| metadata_source | metadataSource | 区分 fictional_demo 与普通录入资料 |

现有 summary 继续作为图书简介扩写，不另造相互冲突的说明字段。书评仍来自 ratings 表；相似推荐依据现有分类及适龄计算，不另建伪书评或冗余推荐表。

商家新增/编辑商品添加可收起的“图书资料”选填区；管理员详情、维护图文及审核详情显示相同字段。新版本的资料随该商品版本审核后公开；旧客户端未传新增字段时保留原值，显式清空与未提交字段分开处理，避免只改价格/简介时丢失资料。

API 公开详情、同步快照和 Android 本地读取共用相同字段；本地相似推荐使用与联网一致的可见性及排序规则。保持现有 Product 交易模型及购物车字段用途，新增书籍资料独立解析，降低对结算和订单快照的影响。

## 9. 既有内容填充与数据保护

1. 实施前生成数据库备份和 20 本书的更新清单，记录商品 ID、当前发布版本及将更新的内容字段。
2. 数据库结构迁移仅增添字段；填充操作事务执行并校验商品 ID、书名和目标版本，发现意外变更时停止该项，避免覆盖其他人的更新。
3. 20 本书逐一补充匹配题材的简介、作者、出版社、日期、目录及编辑推荐，保留原价格、库存、分类、图片、店铺、订单、评价、收藏和账号。
4. 填充后更新同步需要的商品版本信息，维护过程可追溯；重复执行不重复造商品，也不覆盖之后人工维护的非空资料。
5. 同步补充 Android 内置公开演示资料。旧安装本地数据采用一次性按商品匹配的缺失字段补齐，不全量重置、不重新导入历史业务快照；有待同步编辑的商品不能被内置资料覆盖。
6. 虚构演示资料在资料区做简洁来源提示；实际用户评价和个人信息不写进公开演示包。

## 10. 实施后的验收

- 背景六项均可见；选中、切换、再次取消、重启保持和买家/商家共用均可验证。
- 详情无试听入口，20 本商品各项资料正确、无截断或异常空白，原收藏、图集、购物车和购买逻辑回归通过。
- 目录及作者弹层的圆角、关闭、滚动、长文换行、系统返回及状态恢复通过实际设备截图和操作验证。
- 浅色、深色、壁纸、纯色及小屏/放大字体组合检查。
- 已有评价和数量保持，相似推荐不含本书/重复/不可见商品。
- 断网首次安装、旧版离线升级、恢复联网，以及商家编辑→管理员审核→App 同步后的字段均不丢失。
- 相关 Android 构建/lint、API/同步回归及网页图书资料编辑检查；未执行的检查不宣称通过。
