# Android 1.2.0 · 三端界面改版前基线

Android `1.2.0`（versionCode `34`），Debug 模拟器演示包，包名 `com.huimeng.bookshop`，最低 Android 8.0（API 26），目标 API 35。

## 相对 1.1.6 的改动

- 买家和商家主界面新增可拖动的 AI 助手。管理员网页新增 AI 管理，支持按角色使用助手、配置兼容服务及查看调用统计。配置的 API Key 在服务端加密保存。
- 买家和商家在登录时选择身份。服务端按当前身份校验权限，同步队列按账号和身份恢复。商家审批通过后，以商家身份重新登录。
- 商家工作台集中展示经营待办。商品和订单列表支持搜索与状态筛选，商品编辑补充库存与绘本资料维护，订单详情和售后展示按真实状态更新。
- 服务端纳入 SQLite 规范化结构、兼容旧数据的读取和同步，以及独立的备份、预检、校验、切换与恢复工具。日常启动采用数据库现有迁移状态。
- 更新默认头像资源和管理网页的商品、导航及主题细节。

## 使用方式

启动该标签对应的 API 和管理员网页，再向 Android 模拟器安装 `huimeng-1.2.0.apk`。默认 API 为 `http://10.0.2.2:3000/api/v1/`。既有环境可先按控制中心流程备份。数据库、用户上传和本地配置由各环境自行管理。
