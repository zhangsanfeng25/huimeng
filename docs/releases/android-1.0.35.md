## 相对 1.0.34 的改动

- 登录框内显示提示，输入后消失，不再上浮遮挡相邻输入框。
- 首页“查看全部”与年龄、主题分类进入独立绘本结果页，支持搜索、价格排序和分页。
- 轮播支持从最后一张滑到第一张，以及第一张反向滑到最后一张；保留自动播放和离开暂停。
- 本地旧服务已重载，作者主页与帖子详情返回相同的当前用户点赞状态。已点赞显示红色实心，未点赞显示灰色空心，获赞数量不代表当前用户已点赞。
- 评论时间按设备本地日期显示：今天 `HH:mm`，本年非今天 `MM-dd`，往年 `yyyy-MM-dd`。
- 下单、支付、发货、确认收货同步生成买家与对应商家的未读消息，失败或重试不重复生成。网页管理端代处理发货和完成也同步通知。
- 消息页进入时更新；前台订阅订单/消息 SSE 事件，断线时每约 5 秒同步，离开后停止。

## 使用

此包为 Debug 签名的模拟器演示包，API 为 `http://10.0.2.2:3000/api/v1/`。覆盖安装即可；本机共用 API 已加载本次更新。换到其他电脑时需使用更新后的服务器源码，并在控制中心重新启动服务。

实体手机需配置电脑局域网 API 地址后重新构建；未做真机及 API 26 设备验收。订单支付与物流沿用现有演示流程，不连接真实支付或快递服务。
