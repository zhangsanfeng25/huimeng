# 绘梦书城 Android 1.0.36

更新说明：**保持现有界面和操作流程，减少 Android、网页与 API 的重复计算和资源分配，并汇总上传此前的界面修复。**

相对上一正式发行版 1.0.33：

- 统一注册、欢迎页与登录主题；优化胶囊导航、地址卡片和退出按钮。
- 修复登录提示、全部绘本/分类跳转、轮播首尾循环、详情与作者主页点赞、评论时间及订单消息提醒。
- 优化购物车读取和封面绘制，复用格式器、图片地址前缀与 SQL 执行器，减少网页筛选和图表重算；保留即时权限查询、事务及刷新时序。
- 修复日志测试的过期日期样例，生产三天日志规则保持。

安装附件 `huimeng-1.0.36.apk`（versionCode 26，32,311,743 字节）。此为 **Debug 签名的模拟器演示包**，最低 API 26、目标 API 35，接口为 `http://10.0.2.2:3000/api/v1/`。覆盖安装；其他电脑需更新源码并通过控制中心重启服务。实体手机需改为电脑局域网地址后重新构建。历史 APK、标签及 Release 保留。

验证：网页/API lint、build 和完整 npm test 通过（47 项服务端测试及实时同步、维护、控制中心回归）；Android 构建、lintDebug 通过（0 errors、479 warnings）。API 34 模拟器完整交互回归 38 项通过，另外五项行为保持检查通过，共 43 项。160 个封面画面、10,560,000 个像素与旧 1.0.35 一致，随测试 APK 附带的黄金哈希比较也通过；购物车、资产地址及搜索草稿、分类、排序和清空状态的重建行为保持。

限制：未验收实体手机及 API 26 设备；支付与物流仍为演示流程，部分演示商品缺原图，继续显示现有占位。此轮保持社区列表从详情返回后的既有刷新行为，点赞一致性验收针对详情与作者主页。
