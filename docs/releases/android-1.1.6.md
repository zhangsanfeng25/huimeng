# Android 1.1.6（界面优化前备份基线）

版本：`versionName 1.1.6`、`versionCode 33`，Debug 构建，包名 `com.huimeng.bookshop`；minSdk 26、targetSdk 35，默认模拟器 API 为 `http://10.0.2.2:3000/api/v1/`。

正式发行版：[android-v1.1.6](https://github.com/zhangsanfeng25/huimeng/releases/tag/android-v1.1.6)。本版保存已完成的功能修复，作为下一轮局部界面优化前的基线；不包含新生成的界面概念图或尚未实施的页面改版。

## 相对 1.1.5 的实际改动

- 登录成功直接进入对应账号空间，移除重复关联弹窗；退出立即清除会话及头像，游客显示“登录”。已在线验证账号可在本机校验密码离线登录，注册必须联网。
- 买家消息导航整合商家会话及系统通知，支持查看、发送、已读与未读。付款成功显示五秒倒计时并返回来源页面。
- 部分商品、数量及金额售后：支持分次申请、商家初审、平台复核、退货、退款、剩余数量履约及库存准确恢复，服务端重新校验并防止重复退款。
- 增加邮箱/电话匹配账号的演示找回密码；匹配已保存联系方式后重置并使旧会话失效。仅适合本地 DEMO，不具备短信/邮件验证码或生产身份核验。
- 后台反馈及售后复用居中详情弹窗；侧栏分类折叠；跨反馈/售后模块切换清空筛选，同模块打开详情保留筛选。
- 补齐20张默认绘本示意封面，复用已有绘制样式；商家上传优先。全额退款后隐藏再次申请，剩余额度为空时阻止空表单。
- 开启 Gradle 构建/配置缓存，移除未使用的 resolver 声明，减少本地数据库重复 JSON 序列化；不宣称已证明 Android Studio 冷启动提速。

## 安装与运行

附件 `huimeng-1.1.6.apk` 为正常包名的 Debug 模拟器演示包，需配合本标签对应的网页/API源码运行。启动控制中心服务后安装使用；管理员网页与APP应连接同一数据库。

新环境需运行迁移，包含 `011_partial_after_sales.sql`；不会通过源码上传同步现有业务数据。部署前请使用控制中心备份，业务数据库、上传图片、本地配置及密钥不纳入源码提交。

本版保留历史 Release、标签、APK及本机历史安装包。全新界面优化未实施；后续沿用现有风格做局部增减。
