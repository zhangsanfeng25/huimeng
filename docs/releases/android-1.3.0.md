# Android 1.3.0

Android `1.3.0`（versionCode `35`），Debug 演示包，包名 `com.huimeng.bookshop`，最低 Android 8.0（API 26），目标 API 35。默认 API 地址为 `http://10.0.2.2:3000/api/v1/`。

## 相对 1.2.0 的改动

- 完成买家、商家与管理员三端界面改版，优化导航、首页、商品详情、搜索与历史、账户和外观设置、商家商品/订单管理及管理员审核和 AI 管理页面。
- 补全本地账户与控制台同步流程，改善离线反馈、售后、社区和资料操作；同步队列按账号与角色处理。
- 修复付款流程恢复、订单状态投影及付款成功后的页面返回和购物车清理。支付仍为演示方式，不接真实支付渠道。
- 完善 AI 助手和兼容服务商配置；改进商品目录内容与分类示例商品填充脚本。
- 搜索记录按用户隔离保存，最多保留 8 条；商品详情底部收藏改为图标按钮并调整购买操作区。

## 使用方式

先按项目说明启动管理网页和 API，再安装 `huimeng-1.3.0.apk`。真机连接电脑服务时，需将 Android API 地址改为电脑局域网地址；默认模拟器地址不能直接供实体手机访问。更新服务端源码后，通过控制中心重启服务加载新代码。

- `npm run lint`、`npm run build` 通过；完整 `npm test` 通过，服务端 147 项测试及启动准备、日志、实时同步、维护和控制中心检查通过。

- API 34 隔离模拟器通过 5 项定向检查：离线付款结果和购物车清理、搜索空态、搜索候选及清空、商品详情操作栏文字排版、账户设置入口。
- 全量 Android UI 测试未宣称通过：部分测试类继承了导航基类的旧断言（含旧分页搜索和已移除的导航选中底色），另有模拟器系统界面无响应影响的检查。未完成实体手机和真实账号验收。

## 已知限制

- APK 是 Debug 构建；付款、物流和短信不构成真实第三方交易服务。
- 新增分类示例书目填充脚本不会自动导入到其他环境的业务数据库。
- 实体手机、真实账号及真实 AI 服务商配置未在本次发布中做验收。
