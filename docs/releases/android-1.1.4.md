# Android 1.1.4（三端服务完善，本地交付）

版本：`versionName 1.1.4`，`versionCode 31`，Debug 构建。包名保持 `com.huimeng.bookshop`，模拟器 API 为 `http://10.0.2.2:3000/api/v1/`。

相对本地 1.1.3：

- 管理端明确“商品分类”入口，新增售后管理和留言反馈页面，提供阶段操作、详情记录、筛选和回复。
- 买家新增退款／售后、商家消息与意见反馈入口；商品和订单可联系商家，订单可申请或查看售后。
- 商家新增买家消息和售后管理，可提交初审意见、确认收到退货；平台复核并登记演示退款。
- 聊天支持订单／商品上下文、已读位置、历史分页、按账号隔离的缓存和草稿、重复发送保护。
- 售后进行中暂停履约，完成后显示“已退款”；重复退款不重复恢复库存，原订单历史保留。
- 未登录网络账号购买时明确说明仅在本地保存；付款待同步时等待服务端回执，不将本地意向显示为平台付款成功。
- 控制中心导出包含新增 8 张售后、聊天和反馈表；网页升级后旧资源失效时提供重新加载入口。
- 按现有配色、图标和卡片调整入口、箭头、聊天气泡、按钮间距与窄屏布局；按售后类型隐藏无关的退货字段。

最终安装包：`output/android-1.1.4/verified/huimeng-1.1.4.apk`。`final/` 中保留的是前一轮候选构建，本次应使用 `verified/` 文件。
