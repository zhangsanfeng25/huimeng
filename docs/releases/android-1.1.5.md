# Android 1.1.5（三端服务完善与付款修复）

版本：`versionName 1.1.5`、`versionCode 32`，Debug 构建；包名 `com.huimeng.bookshop`，默认模拟器 API 为 `http://10.0.2.2:3000/api/v1/`。

GitHub 正式发行版：[android-v1.1.5](https://github.com/zhangsanfeng25/huimeng/releases/tag/android-v1.1.5)。APK 为 Debug 模拟器演示构建，发行版设置为正式版并设为 Latest。

相对上一次 GitHub 发行版 1.0.36，合并此前本地交付内容：

- Android 增加私有 SQLite、本地操作队列、网络账号关联与幂等同步；控制中心增量构建和运行日志优化。
- 分类结果页调整，完善图书出版资料、目录／作者弹层、商家资料维护与背景选择。
- 管理员补齐商品分类、售后审核、留言反馈；买家与商家增加售后、订单联系和消息聊天；控制中心可导出聊天及售后数据。

相对本地 1.1.4 的追加修复：

- 订单详情显示当前状态和实际操作记录；合并售后审核、退货与退款历史，不提前展示尚未发生的运输或完成步骤。
- 修复付款只停留在本地意向的问题：缺少登录时进入原账号登录，返回原付款页；等待服务端回执后才显示成功。
- 已排队付款继续查询确认，不重复提交；断网、登录过期和超时提供明确说明及重试。
- 修复旧请求影响新登录，以及确认查询中重试导致界面卡住的竞态。
