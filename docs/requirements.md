# 需求范围与实现矩阵

| 模块 | 必要功能 | 当前实现位置 |
| --- | --- | --- |
| 管理后台 | 登录、工作台、用户、商家、分类、审核、商品、订单、评价、社区、通知、日志、设置 | `html/` 与 `server/src/modules/admin.ts` |
| 用户端 | 注册登录、首页、分类、搜索、详情、收藏、购物车、地址、结算、支付、订单、评价、社区、评论、消息、个人资料 | API 已实现；Android 导航与数据加载已接入，复杂表单页面继续按相同接口扩展 |
| 商家端 | 角色登录、商品、提交审核、订单、发货、社区和资料 | `server/src/modules/shop.ts` 与 Android 商家导航 |
| 数据库 | 身份、商家、商品版本、库存、订单、社区、通知、日志、设置 | `server/migrations/001_initial.sql` |
| 安全 | scrypt、令牌摘要、角色与归属校验、限流、参数绑定、Helmet | `server/src/core/` 与各模块路由 |
| 演示数据 | 1 管理员、2 商家、3 用户、20 本绘本 | `server/scripts/seed.ts` |

核心闭环：商家新建并提交商品 → 管理员审核 → 用户浏览并下单 → 模拟支付 → 商家模拟发货 → 用户确认收货并评价。
