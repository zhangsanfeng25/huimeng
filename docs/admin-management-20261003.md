# 管理端修复实施范围

沿用当前网站品牌、配色和组件，参考 yafa-ui-dashboard 的内容层次与自适应规则。

1. 修复动态时间线通用 primary 类名冲突、长文字重叠及列表尺寸。
2. 用户与商家详情显示独立关联内容列表，按账户/店铺 ID 精确查询；商品、订单、帖子、评论使用现有管理入口，支持直接定位。
3. 扩充分类预设，分类类型与名称使用下拉；保留现有分类 ID 和商品关联，通过同一服务端目录同步 Android。
4. 评价删除增加确认与后台软删除，保留订单评价关联及审计；社区评论复用已有删除接口。
5. 帖子详情补全封面与图片数组兼容，真实无图时明确提示。
6. 仅顶栏显示一个按秒更新的时钟，连接异常在下方提示；为实时流增加心跳与失活检测。
7. 接口在隔离数据库验证，前端运行检查后整理交付记录；不使用实际业务数据做删除测试。
