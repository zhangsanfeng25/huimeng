绘梦儿童管理网站 + Android App 共用服务
=====================================

推荐启动入口：huimeng\html\网站启动.vbs（无命令窗口闪现）
网站启动.bat 是兼容入口，Windows 可能短暂显示命令窗口。
点击控制中心“打开服务”，首次运行自动安装依赖、初始化共享数据库。
启动校验源码与构建产物；未变化时复用构建，变化时重建，已有数据不会清空。
网页：http://127.0.0.1:3000/login
健康检查：http://127.0.0.1:3000/api/v1/health （应返回 service=huimeng-api）
Android 模拟器：http://10.0.2.2:3000/api/v1/
关闭时回到同一个控制中心点击“关闭服务”。

先关闭旧版控制中心服务，再解压新版覆盖 huimeng 文件夹；不要同时启动两套服务。
网站与 App 共用的数据库：huimeng\server\data\huimeng.db
旧版 html\server\data\huimeng.db 会保留，但不再参与同步。
压缩包不携带数据库文件，覆盖不会清空已有数据。

启动失败可在控制中心右上角设置中查看运行日志。
运行日志最新在顶部，保留三天（72 小时）；DEBUG 同时显示错误。
手机新增内容通过共用 API 写入数据库，网页收到推送后自动刷新。
Node.js 优先使用 D:\ruanjian\node.js，首次安装依赖需要联网。
根目录 start-dev.bat 只转发到同一个控制中心，不需要单独启动。

控制中心数据管理（2026-10-02）
- 备份数据库：在线备份 SQLite，并保存 server/uploads 图片、完整性及哈希清单。
  默认目录 server/data/backups/backup-*，不能只复制 database.sqlite 作为完整备份。
- 恢复数据库：先关闭服务，选择完整备份目录，验证后确认恢复。
  自动备份恢复前数据；恢复后重新打开服务，网页与手机重新登录。
- 导出业务数据：选择目录，生成 12 类 CSV 和 JSON，不包含密码散列和令牌。
- 查询管理记录：按本地日期和关键词筛选，最新记录在上，最多 1000 条。
  管理操作和本地备份/恢复/导出记录同时显示。业务审计记录不按运行日志三天规则删除。

网页商品审核点“查看”即可核对对应版本的介绍、封面、详情图、价格和库存，并通过或填写原因驳回。
控制中心日志与记录窗口已修复筛选栏遮挡；选中管理记录可在下方查看、复制完整详情。
按钮悬浮以短暂颜色渐变提示，不改变大小或位置；记录列表只计算可见行高度。
启动时校验并复用未变化的构建，代码、配置或产物变化后自动重新构建。
商品列表“查看 → 维护商品图文”支持上传真实图片、设置封面和保存图文。
原图不在项目或来源不可访问时显示明确提示，需要在此补充真实图片；不自动替换为其他商品图片。
商品、社区图片可点击预览；顶部显示实际连接状态与最近成功读取时间。
